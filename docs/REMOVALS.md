# DarkFleet Removal Log

> Hard rule: no useful capability disappears silently. Every intentional removal
> records old feature, reason, replacement, migration, and verification.
> An undocumented removal is a failure.
>
> Dated entries are historical. Where a later change made an earlier entry
> wrong, the earlier entry is annotated in place with the correction and the
> superseding date — it is not rewritten to look prescient.

## 2026-10-02 — the synthetic mode is deleted, not gated

One batch, eight commits: `f3540c1` `fe6a41b` `b1cd084` `d6f99d8` `6ede0b4`
`7764af8` `f6b8ed0` `be9cd07`. The previous entry set removed DEMO *from the
product* while keeping a synthesiser alive as a test harness behind
`Settings.allow_synthetic_scenes`. That narrower scope is superseded: there is
no synthesiser, no switch, and no settings field. The reason is not that a flag
was inconvenient but that a scene generator kept alive for tests is still a
scene generator, and `tests/test_no_synthetic_in_product.py` now asserts the
module does not exist at all.
